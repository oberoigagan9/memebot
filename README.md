
# Meme Bot

A simple Discord bot that fetches and sends memes using the [Meme API](https://meme-api.com).

## Features

- Responds to `$meme` command by fetching a random meme from the Meme API.

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your_username/meme-bot.git
   cd meme-bot

2. Install the required dependencies:

   pip install discord.py requests

## Usage

1. Replace 'My Token' in client.run('My Token') with your actual Discord bot token.

2. Run the bot:

   python bot.py
   
3. Invite the bot to your Discord server and use the $meme command to get a random meme!
